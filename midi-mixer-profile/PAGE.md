# deej MAX7219 (Pro Micro)

Профіль для контролера на Arduino Pro Micro з прошивкою `arduino/midi-mixer-5-sliders-matrix-pio`.

## Що є в профілі

- **5 груп-повзунків** (CC1–CC5). Повзунок 1 — Master, лінія на всю висоту матриці.
- **Зворотний зв'язок на матрицю**: MIDI Mixer надсилає поточну гучність назад на CC1–CC5, матриця показує її.
- **Кнопки 1–5** (ноти 60–64) — Mute для повзунків 1–5, курсор на матриці блимає, коли канал заглушений.
- **Кнопка 6** (нота 65) — окрема група з Mute, призначай на що хочеш (наприклад, мікрофон).

## Як користуватись

1. Проший плату: `pio run -t upload` у папці прошивки.
2. Пристрій має називатись **MAX7219 Mixer**. Якщо Windows показує іншу назву — вибери плату вручну у полях Input і Output зверху.
3. Додай програми (Spotify, Discord, Chrome...) у групи повзунків.
