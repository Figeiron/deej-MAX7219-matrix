# Changelog: deej-vanilla

All notable changes to the plain deej controller (no matrix). Tags: `deej-vanilla/vX.Y.Z`.

## [1.0.0] - 2026-10-26

First release of this fork.

- Arduino sketch for Pro Micro / Leonardo: 5 sliders, 6 buttons, deej serial protocol (`s…|b…`).
- deej desktop app with button support (from [Miodec/deej](https://github.com/Miodec/deej)).
