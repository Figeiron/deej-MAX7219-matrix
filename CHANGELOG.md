# Changelog: deej-matrix

All notable changes to the deej controller with the MAX7219 matrix. Tags: `deej-matrix/vX.Y.Z`.

## [1.0.0] - 2026-10-26

First release of this fork.

- PlatformIO firmware for Arduino Nano: 5 sliders, 6 buttons, deej serial protocol (`s…|b…`).
- MAX7219 4×8×8 matrix shows slider positions: slider 1 as a full-height line, the others as 2-row cursors.
- deej desktop app with button support (from [Miodec/deej](https://github.com/Miodec/deej)).
